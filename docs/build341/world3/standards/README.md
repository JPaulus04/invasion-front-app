# Outpost Zero World 3 - Part 1, standard enemies

This package contains five approved standard enemies, 220 body animation frames, 80 separate effect frames and five masters.

Keep each enemy's folder and its manifest-relative paths under assets/enemies/world3. Add the folders to the game's resource bundle through the existing project process. Follow the per-enemy integration notes and cue sheets in handoff/. Use the MP4 previews as art QA evidence. Gameplay wiring and iOS simulator checks belong to the Codex integration pass.
